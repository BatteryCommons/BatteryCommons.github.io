Battery Data Commons

A curated, continuously updated metadata commons for battery datasets. Discover, compare, and cite public battery data from trusted repositories worldwide.

Find Datasets → Learn More

What We Provide

🔍 Curated Discovery

Every dataset in the Commons has undergone human curation. We verify relevance, quality, and accessibility — no auto-generated or unreviewed records.

📊 Structured Metadata

Consistent metadata across all entries: chemistry, format, temperature range, access conditions, and associated publications. Compare datasets at a glance.

🔗 Persistent Links

We index metadata, not measurements. All data access occurs via persistent DOIs and repository landing pages, ensuring reliable long-term access.

📦 Versioned Releases

Every public update is a versioned snapshot. Cite specific releases for reproducibility, and track how the catalogue evolves over time.

🔬 Research Infrastructure

Designed as long-term research infrastructure for the battery community, not as a static project webpage.

🤝 Community Contributions

Propose new datasets or corrections via our issue-based submission system. All contributions undergo the same rigorous human review.
