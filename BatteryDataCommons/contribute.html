Submit a Registry Entry

Help expand the registry by proposing new entries or suggesting corrections to existing records.

📋 Before You Submit

All submissions undergo community review. Please ensure your proposed registry entry meets the inclusion criteria before submitting.

Submission Process

Check Existing Records

Search the catalogue to verify the registry entry is not already included. If it exists but has errors, use the Suggest a correction action on that entry page.

Verify Inclusion Criteria

Ensure the source data meets all requirements: publicly accessible, contains battery measurements, has clear access conditions, and is deposited in a reputable repository.

Gather Required Information

Collect: registry entry title, repository URL, DOI (if available), category, chemistry, data level, format, temperature range, license, and any associated publications.

Submit via GitHub

Open an issue using the submission template. Provide all required fields and any additional context that would help reviewers. If your submission is accepted and you opt in, we may acknowledge you on the Contributors page.

Open Submission Form →

Await Review

Submissions are reviewed by community curators. The source record is verified, and clarifications may be requested. Approved entries are added in the next catalogue release.

Inclusion Criteria

To be included in the Battery Data Commons, registry entries must:

  • Be publicly accessible — Available via a persistent URL or DOI
  • Contain battery measurements — Actual experimental or operational data, not simulations without validation
  • Have clear access conditions — License or terms of use must be stated
  • Be deposited in a reputable repository — Zenodo, Figshare, institutional archives, etc.
  • Include sufficient context — Chemistry, format, and experimental conditions should be documented

Types of Contributions

🆕 New Registry Entry

Propose a battery data record not currently in the catalogue.

✏️ Correction

Report errors in existing records (wrong DOI, outdated link, incorrect metadata).

🔗 Add Publication

Link a new publication to an existing registry entry.

💡 Suggestion

Propose improvements to categorisation, metadata schema, or website features.

Review Timeline

Submissions are typically reviewed within 2–4 weeks. Complex cases or source records requiring additional verification may take longer. Approved records are batched into periodic releases rather than published individually.

Questions?

If you're unsure whether a record qualifies or need help with the submission process, feel free to open a discussion on the GitHub Discussions before submitting.
